# ZINE_001 — Our Memory

This is the first example publication created with ZineOS.

`ZINE_001` is a draft zine concept based on hand-drawn page sketches.

It explores memory, travel, photographs, maps, reflection, and unfinished personal meaning.

---

## Purpose

This example exists for two reasons:

1. To serve as the first real editorial test of ZineOS.
2. To help the system grow from actual publishing practice.

Rather than designing a theoretical example, this publication is based on a real zine idea.

---

## Editorial Themes

This zine currently explores:

- memory
- travel
- photography
- remembered places
- unfinished experiences
- future return

---

## Notable Structural Feature

One of the most important pages in this zine is the **Memory Index**.

The Memory Index is not treated as a traditional table of contents.

Instead, it represents memory as a partially filled grid.

Filled cells indicate pages that contain memory-bearing moments.

Empty cells suggest memories not yet recorded, unfinished meaning, or space left open.

In this first version, the Memory Index is represented through layout semantics rather than a dedicated Block type.

This allows ZineOS to express the idea without prematurely adding a new Block.
