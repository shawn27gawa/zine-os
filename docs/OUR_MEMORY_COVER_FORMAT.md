# OUR MEMORY Cover Format

The `OUR MEMORY` publications share a recognizable cover structure while
keeping image selection and ordering under creator control.

## Format

- Use the existing `memory-index-grid` layout.
- Arrange 30 creator-selected photographs in a 5 × 6 grid.
- Keep source photographs unchanged and apply monochrome treatment only in the
  rendered cover.
- Reserve the lower 26% of the A5 page as a quiet information band.
- Use a small creator-approved context line above the title.
- Set `OUR MEMORY` as the large lower title.
- Keep the grid edge-to-edge above the information band.

## Back cover

- Use the existing `closing-memory-grid` layout.
- Reuse the same 5 × 6 monochrome image set as the front cover.
- Fill the complete A5 page without an information band or title.
- Preserve the creator-approved image order unless a different ending rhythm is
  explicitly requested.

The default crop is centered `cover`. Individual crops may be adjusted through
ZineOS Studio without changing the original image files.

This is a series format, not a universal ZineOS cover requirement. ZineOS must
not automatically choose photographs, context copy, order, or crop on behalf of
the creator.
