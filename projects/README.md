# ZineOS Projects

Creator publications created with `scripts/bootstrap_project.py` live here.

`examples/ZINE_001/` is a completed reference publication. Projects in this
directory start from the neutral basic template and do not inherit ZINE_001's
story, photographs, map, page sequence, or visual decisions.

Each project owns its `zine.yaml`, approved assets, inbox inventory, and review
artifacts. Source photo inboxes may remain outside the repository and are never
modified by bootstrap.
